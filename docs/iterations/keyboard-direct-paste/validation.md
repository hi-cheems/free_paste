## 手工验证矩阵

手工验证前，统一先执行：

```bash
./scripts/build-fixed-debug.sh
open .deriveddata/Build/Products/Debug/FreePaste.app
```

说明：
- 不要直接运行系统 `DerivedData` 中的临时产物
- 固定使用仓库内 `.deriveddata` 路径，可以减少 `Accessibility` 权限重复授权
- 如果已经给该固定路径的 app 授权，后续重复验证通常不需要重新勾选

### 主路径

1. 打开 Notes、TextEdit 等应用
2. 复制多段文本
3. 按 `Cmd+Shift+V`
4. 在搜索框中输入
5. 仅通过键盘进入列表
6. 用键盘导航条目
7. 按 `Return`
8. 确认 FreePaste 关闭
9. 确认原应用重新激活
10. 确认选中的文本被成功粘贴

补充排查：
- 如果已经确认 FreePaste 关闭、原应用回到前台，但文本仍未出现，先检查目标应用或常驻工具是否拦截了 `Cmd+Shift+V`、`Cmd+V` 或其他相关快捷键
- 优先在 Notes、TextEdit 这类快捷键定制较少的应用中做基线验证，再回到问题应用复测

### 权限路径

1. 撤销 FreePaste 的 `Accessibility` 权限
2. 触发直接粘贴
3. 确认系统权限提示出现
4. 确认不会出现“假成功”
5. 授予权限
6. 再次尝试并确认流程成功

### 边界情况

1. 没有任何剪切板历史
2. 搜索没有结果
3. FreePaste 打开期间原应用被关闭
4. 用户通过状态栏图标而不是快捷键打开 FreePaste
5. 剪切板文本非常长
6. 快速连续打开和关闭 `popover`
7. 目标应用存在自定义快捷键或全局热键拦截
8. 列表快捷键被用户改成自定义组合键
