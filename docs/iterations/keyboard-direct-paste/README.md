# 键盘导航 + 直接粘贴迭代

> 创建时间：2026-03-15
> 说明：本目录是该迭代的历史档案。里面的“范围”“非目标”“当前结论”都应按当时阶段理解，不等同于今天的全局现状。

这个目录保留 2026 年 3 月键盘导航与直接粘贴迭代的设计与执行文档。当时的核心目标是：支持键盘驱动的历史选择，并将内容直接粘贴回之前正在使用的应用。当前布局、搜索模式和安装流程见 [文档总览](../../README.md)。

归档时状态：
- 本迭代已完成主链路实现与手工验证
- 当时的验收未发现新的功能问题，不代表后续所有版本或目标应用均已验证

## 目标

把当前流程：

`打开 FreePaste -> 点击一条记录 -> 切回原应用 -> 按 Cmd+V`

升级为：

`打开 FreePaste -> 用键盘选择 -> 按 Return -> 自动粘贴`

## 范围

本次迭代包含：
- `popover` 内的键盘导航
- 选中行的高亮与焦点行为
- 打开 FreePaste 时记录之前的前台应用
- 确认选择后关闭 `popover`
- 请求 `Accessibility` 权限
- 向原应用发送粘贴事件（`Cmd+V`）

本次迭代不包含：
- 多格式剪切板支持
- 设置面板
- 超出键盘反馈范围的视觉重设计
- 同步、隐私规则、应用黑名单

## 预期结果

完成本次迭代后：
- 用户可以通过 `Cmd+Shift+V` 打开 FreePaste
- 用户可以不使用鼠标选择历史记录
- 按 `Return` 后会复制选中项、关闭 `popover`，并将内容粘贴回原应用
