# FreePaste 隐私功能说明

> 创建时间：2026-03-23
> 最后更新：2026-10-15
> 这是产品行为说明和候选功能备忘，不是隐私政策或法律文件。

## 当前已实现

| 能力 | 行为与边界 |
| --- | --- |
| 本地历史 | Core Data / SQLite 保存文本、图片、文件 URL 和文本原始格式；当前没有云同步 |
| 应用黑名单 | 根据当前前台应用的 bundle ID 阻止采集结果进入历史和批量队列 |
| 暂停历史记录 | 手动暂停、暂停 5 分钟 / 15 分钟、恢复；菜单栏右键和设置页有入口，面板显示状态 |
| 历史裁剪 | 最大条数、保存容量、保留天数；收藏不参与自动淘汰 |
| 清理 | 可删除单条记录；“清空”仅删除未收藏历史，不清空收藏 |

来源应用只在黑名单判断时读取，不写入记录，也不显示来源名称或图标。文件条目保存 URL，不保存文件内容的副本。

应用没有实现历史数据库加密、敏感内容分类、关键词 / 正则过滤、图片 OCR 或同步。App Sandbox 与本地存储不是“内容已经加密”或“自动排除密码”的保证。

## 暂停记录的准确含义

暂停只阻止新内容进入持久历史，不阻止查看、搜索、预览、重新复制或直接粘贴已有条目。

- 暂停状态会保存，应用重启后仍有效；定时暂停到期自动恢复。
- 再次暂停覆盖此前状态，手动恢复立即生效。
- 暂停时跳过的历史不会缓存，也不会恢复后补录。
- 黑名单检查在暂停检查之前，不记录被屏蔽应用的内容。
- **批量模式不受历史暂停影响**：这是用户明确启动的临时收集，但仍遵守应用黑名单。

没有自定义暂停时长、暂停快捷键或“跳过条数”统计。

## 批量数据生命周期

批量队列只在内存中存在，不保存或恢复会话。每次输出或删除移除一项；最后一项移除自动结束，手动关闭清空剩余队列。

队列限制为 200 项及 256 MiB 估算载荷。文件只计 URL 字符串，不读取文件内容用于队列容量统计；该限制不是整个进程的内存上限。

正常记录开启时，批量收集的内容也可能进入历史。关闭批量浮窗不会删除这些历史，也不会清空系统剪贴板；暂停历史才会阻止新内容入库。不要将“队列临时”误读为“复制内容完全不落盘”。

## 安装与数据

DMG 只包含应用包和 Applications 链接，不包含开发者的历史数据库或用户设置。更新 .app 不自动删除用户历史；数据库迁移失败保留原数据，应用可临时回退到内存存储。

辅助功能权限用于恢复应用和派发复制 / 粘贴事件，批量模式还需输入监控。构建签名稳定和安装路径固定有助于减少授权变化，但不承诺更新后永远免授权。详见 [安装与验证](development-workflow.md)。

## 尚未实现的候选能力

候选方向只在实际使用产生需求后评估，不是当前功能或既定实现计划：

- 更细的来源预设和“为何跳过”反馈。
- 可配置的关键词 / 正则规则，先明确丢弃、允许一次或标记敏感的行为，避免静默误伤。
- 一键清理最近一段时间、敏感条目更快过期、降低敏感内容可见性。
- 如未来增加 OCR，再评估识别结果的存储、性能和敏感规则。
- 如未来需要加密或同步，另行定义密钥、备份、恢复及隐私边界。

现有产品明确不记录来源应用，不能为方便未来规则就默认新增 `sourceBundleID` / `sourceAppName` 到条目。任何隐私元数据扩展都需重新确认必要性。

## 维护原则

优先确定、可配置、可解释、低误伤的规则。功能变更同时明确它影响历史、批量队列、系统剪贴板还是已有收藏，并补充相应测试，避免不同入口出现意外例外。

实现入口为 [ClipboardManager](../FreePaste/FreePaste/ClipboardManager/ClipboardManager.swift)、[AppSettings](../FreePaste/FreePaste/AppSettings.swift)、[BatchPasteSession](../FreePaste/FreePaste/BatchPaste/BatchPasteSession.swift) 与 [ClipboardHistoryStore](../FreePaste/FreePaste/ClipboardHistory/ClipboardHistoryStore.swift)。
