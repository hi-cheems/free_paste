# FreePaste 后续方向

> 最后更新：2026-10-15
> 本文区分已完成工作与候选方向；候选不是开发承诺。

## 已有基础

目前已经实现菜单栏入口、自定义快捷键、三类内容采集与持久化、底部横向历史面板、收藏 Key / 内容混合搜索、默认快速搜索与详细编辑、直接粘贴、纯文本粘贴、富文本保留、预览、批量收集 / 输出、黑名单、暂停记录和开机自启。

最近的维护还包含按需加载原始载荷、图像缩略图 / 降采样、有界缓存、增量更新和安全迁移。构建脚本已输出脚本同级的 .app 与 DMG；当前 DMG 仍是开发签名的 Debug 包，不是公证发行版。

完整行为见 [项目说明](project-notes.md)，构建与验证见 [开发文档](development-workflow.md)。

## 近期维护优先级

1. **输入与目标应用兼容性**：保持快速 / 详细搜索的按键边界、中文输入法组词、收藏切换和自定义快捷键稳定；针对可复现的直接粘贴失败补充反馈和回归测试。
2. **长时间高强度使用**：观察大量图片 / 富文本、持续搜索与频繁预览后的内存和响应时间。已有缓存限制不代表进程内存有硬上限，需要真实运行曲线验证。
3. **批量工作流**：覆盖首项选区复制、全局 Cmd+V、拖动换位、方向切换、容量限制和队列清空时机，尤其避免目标应用派发失败与队列状态不一致造成意外。
4. **维护与安装回归**：文档跟随实际代码，保留旧数据库迁移测试；打包失败保留旧 DMG，更新安装保持固定身份与路径。

以上是维护检查方向，不代表这些场景当前均存在已知缺陷。

## 分发候选

当前单机使用可继续使用现有 Debug 构建。公开发布前才评估：

- Release archive / export、Developer ID 分发签名和公证，不能只修改 .dmg 扩展名。
- 明确支持的 macOS 版本和 CPU 架构；当前实测产物为 arm64，未证明 Intel 或 Universal 支持。
- 最终安装包在独立 Mac / 测试用户上的首次安装、更新、下载隔离与离线验证。
- 证书和公证凭据的安全配置，避免加入仓库。

详见 [DMG 调研](dmg-packaging-research.md)。App Store 是单独的分发方向，不能把当前 Debug DMG 当成 App Store 提交包。

## 需求驱动的候选功能

| 方向 | 触发条件与约束 |
| --- | --- |
| 图片 OCR 搜索 | 图片内容找回成为高频痛点；先评估性能、索引更新和隐私。现有手动收藏 Key 不是 OCR |
| 内容隐私规则 | 黑名单和暂停不足以解决实际问题；明确规则、反馈与误伤处理，不默认记录来源应用 |
| 直接粘贴反馈增强 | 有稳定复现的权限或目标应用兼容问题；区分事件派发与实际目标接收 |
| 同步 | 确有跨设备需求，再比较 CloudKit / 局域网方案与安全、冲突、恢复成本 |

旧富文本历史如果当时没有原始格式，无法凭空恢复；这个数据限制不应被写成待修复的格式保存功能。

## 工作原则

优先处理真实使用问题，改动范围小、结果可验证。新能力先明确用户工作流和行为边界，不以扩大功能列表为目标；历史讨论与今天的实现不同，保留在 [迭代档案](iterations/keyboard-direct-paste/README.md)。
